This repository contains advanced RTL (Register-Transfer Level) designs and hardware verification environments developed in SystemVerilog. The focal project is a fully compliant IEEE-754 Single-Precision Floating-Point Adder/Subtractor, demonstrating complex digital logic architecture, synchronous pipeline design, and rigorous functional verification.   Project Highlights: IEEE-754 Floating-Point UnitHardware Architecture: Designed a combinational computational core (fp_adder.sv) encased within a synchronous top-level wrapper (fp_adder_top.sv) that introduces a strict 2-cycle latency pipeline.   Algorithmic Modules: Implemented specialized datapath stages including exponent alignment, a Leading Zero Counter (LZC) for mantissa normalization, IEEE-754 rounding modes, and comprehensive exception handling (Zero, Infinity, NaN, Underflow, Overflow, Inexact).   Advanced Verification: Engineered a robust, timing-aware testbench utilizing the industry-standard Berkeley Hardfloat library as a Golden Reference Model.   Dynamic Scoreboarding & Assertions: Implemented a synchronous shift register pipeline to eliminate Verilog race conditions and bound SystemVerilog Assertions (SVA) to the top wrapper to guarantee mathematical coherence between input operands and hardware output flags.   Simulation: Exhaustively verified across 1100 permutations using Questa Intel Starter FPGA Edition, achieving a 100% success rate on both extreme corner cases (NaNs, Subnormals) and randomized vectors.   Technologies & EDA ToolsLanguages: SystemVerilogVerification: SystemVerilog Assertions (SVA), Berkeley Hardfloat, Dynamic ScoreboardingToolchain: Questa-Intel FPGA Edition
